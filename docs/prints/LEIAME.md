# Capturas do jogo em execução

Todas as imagens são capturas reais do jogo rodando (não são conceitos nem imagens geradas). Origem: execução do projeto neste ambiente de desenvolvimento, renderização por software (Mesa llvmpipe), 1280 × 720, roteiros `graf`, `jogo` e `carro` de `tools_rt/autotest.gd`. Nenhuma foi tirada em celular.
